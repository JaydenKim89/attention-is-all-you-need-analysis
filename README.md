# Attention Is All You Need — From Paper to Implementation

A technical study and from-scratch implementation of the Transformer architecture introduced in **"Attention Is All You Need"** by Vaswani et al.

## Project Objective

The goal of this project is not only to summarize the paper, but to understand the Transformer through:

- Research motivation and architectural design
- Mathematical foundations of self-attention
- From-scratch implementation
- Numerical verification
- Experimental analysis
- Computational and engineering perspectives

## Planned Work

### Paper Analysis
- Problem and motivation
- Transformer architecture
- Scaled dot-product attention
- Multi-head attention
- Positional encoding
- Training methodology and experimental results
- Critical analysis

### Implementation
- Attention calculation by hand
- NumPy scaled dot-product attention
- Multi-head attention
- Positional encoding
- PyTorch implementation
- Transformer encoder and decoder blocks

### Verification and Experiments
- Numerical comparison between implementations
- Attention visualization
- Masking verification
- Sequence-length and computational-complexity experiments
